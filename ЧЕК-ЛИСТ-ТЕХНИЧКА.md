## Шаг 3. Resend — чтобы заявки доходили до почты

Сейчас форма работает, но письмо не уходит: заявка пишется в лог сервера. Пока это так, **все заявки с сайта теряются**.

### 3.1 Регистрация

- [ ] resend.com → зарегистрироваться (бесплатно, 3000 писем в месяц)
- [ ] Domains → Add Domain → `tehgeoproekt.ru`

### 3.2 Записи в DNS

Resend покажет три записи. Вносить их теперь **в Vercel**, а не в Рег.ру — управление зоной переехало туда.

- [ ] Vercel → Domains → `tehgeoproekt.ru` → раздел DNS Records → добавить:

| Тип | Имя | Значение |
|---|---|---|
| TXT | `send` | `v=spf1 include:amazonses.com ~all` |
| TXT | `resend._domainkey` | длинный ключ из панели Resend |
| MX | `send` | `feedback-smtp.eu-west-1.amazonses.com`, приоритет 10 |

- [ ] Добавить отдельно DMARC (Resend его не выдаёт):

| Тип | Имя | Значение |
|---|---|---|
| TXT | `_dmarc` | `v=DMARC1; p=none; rua=mailto:tehgeoproekt@mail.ru` |

- [ ] Вернуться в Resend, нажать **Verify** — статус домена должен стать `Verified`

### 3.3 Ключ в Vercel

- [ ] Resend → API Keys → Create API Key → скопировать (показывается один раз)
- [ ] Vercel → Settings → Environment Variables → добавить `RESEND_API_KEY`, значение — ключ, замочек **включить**
- [ ] Deployments → у последнего **Redeploy**

### 3.4 Проверка

- [ ] Отправить заявку с сайта
- [ ] Resend → Logs: статус `delivered`, не `bounced`
- [ ] Письмо пришло на `tehgeoproekt@mail.ru` и **не в спам**
- [ ] В письме «Показать оригинал» → в заголовках `spf=pass` и `dkim=pass`

Если письмо в спаме — значит какая-то из записей не подхватилась. Напиши, разберём.
