# ТехГеоПроект — сайт

Сайт ООО «ТехГеоПроект»: маркшейдерские работы, аэрофотосъёмка карьеров, проектирование горных работ. Кемерово.

**Домен:** tehgeoproekt.ru
**Студия:** Pribytik Studio, Weblove Method. Собран по стандарту `CLAUDE.md`.

## Стек

Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · IBM Plex Sans / Mono через `@fontsource` (self-host) · Resend + Zod для заявок · Яндекс.Метрика

## Запуск

```bash
npm install
cp .env.example .env.local   # заполнить ключи
npm run dev                  # http://localhost:3000
npm run build                # продакшн-сборка
npm run lint                 # проверка стиля
```

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | Адрес сайта для canonical, sitemap и JSON-LD |
| `RESEND_API_KEY` | Отправка заявок |
| `LEAD_TO_EMAIL` | Куда приходят заявки |
| `LEAD_FROM_EMAIL` | Адрес отправителя, домен должен быть подтверждён в Resend |
| `NEXT_PUBLIC_METRIKA_ID` | Номер счётчика Метрики. Пусто — счётчик не подключается вовсе |

Без `RESEND_API_KEY` форма работает и валидируется, но письмо не уходит — заявка пишется в лог сервера. Это штатное поведение тестового стенда.

`NEXT_PUBLIC_*` вшиваются в бандл при сборке, поэтому после их изменения нужен **пересбор**, а не перезапуск.

## Правила проекта

Полный свод — в `CLAUDE.md` студии. Ключевое:

- Server Components по умолчанию, `'use client'` только где нужна интерактивность
- Только именованные экспорты, никаких inline-стилей, никаких `any`
- Все изображения через `next/image`
- Все тексты в `src/copy.ts` — условие для будущей мультиязычности
- Анимировать только `transform`, `opacity`, `filter`, `clip-path`
- Каждая анимация отключается при `prefers-reduced-motion: reduce`
- Lighthouse: Performance >= 90 desktop, >= 80 mobile
